# arif-rachim.github.io

This repository contains the source and the published build of Arif Rachim's personal site at www.rach.im. The site is a single-page CV and portfolio for a principal application developer. It collects his professional profile in one place for recruiters, clients and collaborators: an introduction, an about section with a skills list, selected projects, work experience, education and certifications, contact links, and a downloadable PDF CV. The page is built with Astro as a fully static site. It uses no UI framework, only a small script that reveals sections on scroll, and the section components share one layout that adds SEO metadata, Open Graph tags, schema.org Person data and a sitemap. GitHub Pages serves the committed `docs/` folder on `main`. Besides the CV page, `docs/` also hosts several separately built apps under their own paths: the HUSO Prep study platform, Stock Watch, a Todo List and TapMeja. The site is live and is updated by hand; there is no CI pipeline.

**Live demo:** https://www.rach.im

## Features

- One page with the sections Landing, About (years of experience and skills), Projects, Experience, Education and Contact
- Downloadable CV at `/arif-rachim-cv.pdf`
- SEO: canonical URL, meta description, Open Graph image, schema.org `Person` JSON-LD, `robots.txt` and a sitemap generated by `@astrojs/sitemap`
- Sections fade in on scroll (IntersectionObserver), skipped when reduced motion is preferred
- Hashed build assets go to `assets/` instead of `_astro/` (`build.assets` in `astro.config.mjs`)
- Custom domain through `CNAME`, plus a `.well-known/atproto-did` file for Bluesky handle verification
- Sub-apps served from the same domain: `/huso/`, `/stock-watch/`, `/todo-list/`, `/tapmeja/`

## Tech stack

Astro 4 · TypeScript · @astrojs/sitemap · GitHub Pages

## Getting started

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev            # dev server at http://localhost:4321
npm run build          # build to dist/
npm run preview        # preview the build
npm run astro check    # type-check .astro files
```

There is no test runner or linter.

## Project structure

```text
src/
  pages/index.astro    the only route; composes the section components
  layouts/Layout.astro page shell, SEO metadata, JSON-LD
  components/          LandingPage, SeasonedEngineer (About), Projects, Experience,
                       Education, Contact, and the shared Page section wrapper
  assets/photos/       portrait and icons
public/                static files copied into the build (CNAME, CV PDF, images,
                       robots.txt, .well-known/, stock-watch/, todo-list/)
docs/                  the published site that GitHub Pages serves (committed)
  huso/ stock-watch/ todo-list/ tapmeja/   separately built sub-apps
```

## Deployment

GitHub Pages publishes the `docs/` folder on `main` as it is. The Astro build writes to `dist/`, which is git-ignored, and nothing copies it into `docs/` automatically. To publish a change to the CV page:

1. Run `npm run build`.
2. Copy the contents of `dist/` into `docs/`. Keep the `huso/`, `stock-watch/`, `todo-list/` and `tapmeja/` sub-directories. `huso/` and `tapmeja/` are not in `public/`, so they are not rebuilt.
3. Commit `docs/` and push to `main`.

The sub-apps are built in their own projects and their output is copied into `docs/`. Files edited directly in `docs/` outside those sub-directories are overwritten on the next rebuild; `src/` is the source of truth for the CV page. See [`CLAUDE.md`](CLAUDE.md) for more detail.
